# svg-roundtrip

## Purpose
导入一个 SVG、改动少量图形、再导出时，只有用户改过的图形才重新生成；没改过的图形、坐标、元素类型和资源保持原来的结构。
这本册子只写用户能观察到的结果。为什么这样实现、持久化键名和已知降级边界，见 [`docs/notes/svg-roundtrip.md`](../../notes/svg-roundtrip.md)。

### Requirement: 未改动的图形不被重建
#### Scenario: SVG-001 三个矩形导出仍是三个
- **WHEN** 导入一个恰好含 3 个 `<rect>` 的 SVG，立即导出
- **THEN** 输出里仍然是 3 个 `<rect>`，没有第 4 个图形，也没有补出来的背景矩形

#### Scenario: SVG-002 原生元素类型不被改写
- **WHEN** 导入含 `rect`、`circle`、`ellipse`、`line`、`polygon`、`polyline`、`path` 的 SVG，立即导出
- **THEN** 每种元素仍以原来的标签出现、数量不变，`rect` 没有被改写成 `path`

#### Scenario: SVG-003 源坐标不缩放
- **WHEN** 导入 128×96、三个矩形分别在 x=10/50/90 的 SVG，立即导出
- **THEN** 三个矩形的 `x`/`y`/`width`/`height` 与源文件逐值一致，不被放大、平移或贴合画布

#### Scenario: SVG-004 源标记细节原样保留
- **WHEN** 导入含 `id`、属性顺序、注释、`defs`、`style` 的 SVG，不做改动直接导出
- **THEN** 未改动元素仍保留原来的 `id`、属性顺序、数值文本、注释和 `defs`/`style` 内容

#### Scenario: SVG-005 带偏移 viewBox 的图不被挪动
- **WHEN** 导入 `viewBox="10 20 128 128"`、矩形从 (10,20) 开始的 SVG，立即导出
- **THEN** 输出里的矩形几何与源文件一致，不因坐标归一化而改变大小或位置

#### Scenario: SVG-006 不补背景图形
- **WHEN** 导入任意只含普通图形的 SVG，立即导出
- **THEN** 输出没有一张覆盖整张画布的额外 `<rect>`，图形数量与导入时一致

### Requirement: 导入不把内容盒贴合画布
#### Scenario: SVG-007 替换示例文档时画布取源尺寸
- **WHEN** 首次打开编辑器，导入一个 128×96 的 SVG 替换掉示例文档
- **THEN** 画布宽高是 128×96，图形停在源坐标上，不为了贴边而缩放

#### Scenario: SVG-008 追加导入时画布只增不减
- **WHEN** 画布是 200×100，先追加导入 300×150 的 SVG，再追加导入 100×80 的 SVG
- **THEN** 第一次之后画布是 300×150，第二次之后仍是 300×150，已导入的图形不被缩回

### Requirement: 只重新生成用户改过的图形
#### Scenario: SVG-009 改一个矩形不动其它图形
- **WHEN** 导入 3 个带 `id` 的矩形，只把第一个向右移动 1 个单位
- **THEN** 输出仍是 3 个 `<rect>`，第一个的 `x` 加 1，另外两个矩形的标记逐字不变

#### Scenario: SVG-010 移动后的矩形仍是矩形
- **WHEN** 导入一个 `<rect>` 并移动它
- **THEN** 输出里它仍是 `<rect>`，没有变成 `<path>`

#### Scenario: SVG-011 移动后的圆弧仍保留 A 命令
- **WHEN** 导入一条含 `A` 命令的路径，只水平移动 1 个单位
- **THEN** 输出里的路径仍含 `A` 命令，没有退化成用 `C` 表示的曲线

#### Scenario: SVG-012 只改几何时保留绘制属性
- **WHEN** 导入一个使用渐变填充、虚线描边的矩形，只移动它的位置
- **THEN** 输出仍引用原来的渐变、保留原来的虚线设置，没有变成纯色或实线

### Requirement: 增删与层序跟着图层面板走
#### Scenario: SVG-013 删除图形时源元素一起移除
- **WHEN** 导入 3 个带 `id` 的矩形，只删除第一个再导出
- **THEN** 输出剩 2 个 `<rect>`，被删那个的 `id` 和标记不再出现，另外两个原样保留

#### Scenario: SVG-014 新增图形以原生类型追加
- **WHEN** 导入若干图形后新画一个矩形，再导出
- **THEN** 原图形原样保留，新矩形以原生 `<rect>` 追加，图形总数加 1

#### Scenario: SVG-015 层顺序变化按图层面板重排
- **WHEN** 导入 2 个矩形，把下面那个移到上面再导出
- **THEN** 输出里两个元素的先后顺序与图层面板一致，两个元素的标记都不变

### Requirement: 原始结构跟着文档生命周期
#### Scenario: SVG-016 刷新页面后仍能保住未改动结构
- **WHEN** 导入含多个图形与圆弧路径的 SVG，等自动保存完成后刷新页面，不改动直接导出
- **THEN** 输出仍保留源元素类型、坐标与标记，圆弧仍是 `A`，没有退回成重新生成的形状

#### Scenario: SVG-017 撤销导入恢复上一份结构
- **WHEN** 已有文档 A，导入文档 B 后撤销
- **THEN** 导出回到 A 的结构，B 的元素一个都不混进来

#### Scenario: SVG-018 重做导入恢复新结构
- **WHEN** 导入文档 B 后撤销，再重做这次导入
- **THEN** 导出回到 B 的结构，A 的元素没有被重复带出

### Requirement: 特殊继承与不可编辑内容
#### Scenario: SVG-019 根 opacity 只作用一次
- **WHEN** 导入一个根节点 `opacity="0.5"` 的 SVG，移动其中唯一一个矩形
- **THEN** 输出里 `opacity="0.5"` 只出现一次，矩形没有因为重新生成而被再压暗一层

#### Scenario: SVG-020 追加导入保留根级填充继承
- **WHEN** 已有文档里再导入一个根节点带 `fill="#ff0000"`、矩形自身不写填充的 SVG
- **THEN** 新矩形仍是红色，已有图形不受这个根级填充影响

#### Scenario: SVG-021 两次导入的同名 id 不串引用
- **WHEN** 先后导入两个都含 `id="paint"` 渐变、各自矩形引用该渐变的 SVG
- **THEN** 输出里两个渐变都还在、各自引用正确，两个矩形没有串成同一种颜色

#### Scenario: SVG-022 不可编辑元素在未改动时原样保留
- **WHEN** 导入一个含 `text`、`image` 和可编辑矩形的 SVG，只移动矩形
- **THEN** 输出里的 `text`、`image` 仍按原标记保留，矩形按新位置输出

#### Scenario: SVG-023 只有不可编辑元素时明确说没有图形
- **WHEN** 导入一个只含 `text`/`image`、没有可编辑图形的 SVG
- **THEN** 界面提示没有可导入的图形，当前文档不被改写

### Requirement: 导入时带回画布名称
#### Scenario: SVG-024 文件根 title 成为画布名称
- **WHEN** 导入一个根节点含 `<title>My Icon</title>` 的 SVG，当前画布仍是未命名
- **THEN** 画布名称变成 `My Icon`，标题输入框显示它，随后导出仍写回 `<title>My Icon</title>`

#### Scenario: SVG-025 已有名称不被导入覆盖
- **WHEN** 画布已经命名为 `Working`，导入一个根 title 为 `Other` 的 SVG
- **THEN** 画布仍叫 `Working`，导出仍然是 `<title>Working</title>`

### Requirement: 空画布导入时画布跟随源尺寸
#### Scenario: SVG-026 新建的空画布导入后跟随源 viewBox
- **WHEN** 新建一个 960×640 的空画布，导入一个 `viewBox="0 0 128 128"` 的 SVG
- **THEN** 画布变成 128×128，图形按源坐标落位，不需要用户再手动改画布大小

#### Scenario: SVG-027 有内容的画布不被小图缩小
- **WHEN** 960×640 的画布上已有图形，再导入一个 128×128 的 SVG
- **THEN** 画布仍是 960×640，新图形按源坐标追加，已有图形不被裁掉或缩小

### Requirement: 辅助功能直接放在画布顶栏
#### Scenario: SVG-028 顶栏辅助按钮替代左侧面板和面包屑
- **WHEN** 打开编辑器
- **THEN** 画布顶栏直接出现网格、网格大小、吸附和桌布控制
- **AND** 左侧不再有辅助标签和辅助面板，顶部不再重复显示「画布 / 文档名」面包屑

#### Scenario: SVG-029 网格和吸附按钮显示开关状态
- **WHEN** 点网格按钮并选择 16 px，再点吸附按钮
- **THEN** 网格显示为 16 px、按钮呈按下态；吸附关闭、按钮呈未按下态

#### Scenario: SVG-030 桌布按钮打开导入与管理面板
- **WHEN** 点顶栏桌布按钮
- **THEN** 弹出桌布面板，可导入图片；导入后显示缩略图、可见、调整、替换和移除操作

### Requirement: 导入后不自动选中图形
#### Scenario: SVG-031 导入后所有图层都未被选中
- **WHEN** 导入一个含多个图形的 SVG
- **THEN** 图层面板里没有任何一层呈选中态，画布上也没有选择框或变换手柄

### Requirement: 画布边缘外保留操作留白
#### Scenario: SVG-032 放大画布后四周仍有空白
- **WHEN** 把画布放大到超出舞台可视范围，并分别滚到画布的左上角和右下角
- **THEN** 画布边缘与舞台边界之间仍留有一段空白，边缘不会直接贴住面板或工具栏
